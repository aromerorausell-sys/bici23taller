# Bici 23 Taller · web

Web de **Bici 23 Taller**, taller de bicicletas en Patraix (València). C/ Pintor Pasqual Capuz, 7 · 698 99 98 49.

**Web publicada:** https://aromerorausell-sys.github.io/bici23taller/

Una bici en 3D (Three.js, modelada por código) que se dibuja, se despieza y cambia de tipo con el scroll; después servicios, Dani y reseñas, y contacto con llamada, WhatsApp, horario y dirección. Idiomas: ES / EN / RU / UK.

Web by Alejandro Romero.

## Estructura
```
index.html     Página completa (HTML, CSS y JS en un solo archivo)
img/           Fotos del taller
src/page.html  Fuente sin cabecera (se usa para la vista previa)
```

## Verla en local
```bash
python3 -m http.server 8080
```
y abre http://localhost:8080
